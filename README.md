Для запуска на новом устройстве:
    1. Установите ROS Noetic и Gazebo.
    2. Установите Python версии 3.14 или новее.
    3. Установите зависимости: выполните source setup.sh — это создаст и активирует виртуальную среду с установленными зависимостями.
        - Для выхода из виртуальной среды используйте deactivate.
        - Для входа в виртуальную среду выполните source ./venv/bin/activate.

    4. Запустите программу: python3 __main__.py.

Программа позволяет:
    - Добавлять новые типы датчиков (типы датчиков различаются по используемому плагину);
    - Добавлять датчики существующих типов;
    - Тестировать датчики (при необходимости пользователь может самостоятельно добавлять тесты).
